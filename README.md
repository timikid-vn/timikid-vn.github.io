# Tính Lãi Lỗ Shopee & TikTok Shop

🌐 **Dùng ngay:** https://timikid-vn.github.io/  ·  Mã nguồn: https://github.com/timikid-vn/timikid-vn.github.io

Web tĩnh tính tiền nhận về, lãi/lỗ, biên lợi nhuận, ROI, giá hòa vốn, ROAS hòa vốn cho Shopee/TikTok Shop (shop thường & Mall).
- Biểu phí: `src/fees.js` (có nguồn, ngày hiệu lực, cờ `verified`). Mọi mức phí sửa được trong giao diện.
- Logic: `src/calc.js`, test: `npm test`. Chạy: `npm i && npm run dev`.
